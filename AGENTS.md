# Правила работы ассистента

## Удаление файлов и данных

- Без прямой просьбы пользователя об удалении ничего не удалять по собственной инициативе. Обсуждение возможного удаления, вопрос о файле, скачивании или неисправности не являются просьбой удалить.
- Никогда не удалять файлы, папки, модели, зависимости или другие данные без предварительного явного разрешения пользователя на конкретное удаление.
- Перед удалением показать точный список объектов с полными путями и дождаться отдельного подтверждения пользователя.
- Общие просьбы освободить место, убрать ненужное, разобраться с установками или объяснить удаление не считать разрешением на удаление.
- Не обходить это правило через скрипты, команды очистки, деинсталляторы, API или инструменты управления приложениями.
